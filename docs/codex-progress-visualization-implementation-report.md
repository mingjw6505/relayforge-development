## 2. 已实现内容

独立源码位于 `companion/`，运行入口和说明见[Companion 使用说明](../companion/README.md)。

### 数据内核

- 显式单一来源，只读日 JSONL，不申请 logger 锁、不修改源文件。
- 字节游标、半行等待、超长记录丢弃、坏记录隔离、文件替换/截断检测。
- 游标和白名单记录事务提交；独立 SQLite 保存缓存和来源身份。
- UUID 声明重放、序号缺失、冲突、结束后事件、路线不连续等质量判断。
- 会话活动与 task_run_id 声明分离；无按时间自动归因。
- 有界快照、7 日/100,000 记录/100 MiB 规范化载荷限制，裁剪后完整性降级。

### 本地服务

- 仅绑定 127.0.0.1，随机端口与临时访问令牌。
- 严格 Host/Origin、重复头拒绝、无跨源 CORS、固定静态资源白名单。
- 健康、能力、快照 GET API；所有执行、修改、审批和任意文件读取接口均不存在。
- 无访问日志、响应 no-store、安全 CSP、反嵌入、鉴权令牌仅在请求头中使用。
- 前台启动、Ctrl+C/终止信号清理；浏览器打开异常也关闭服务和缓存。

### 界面

- 中文会话列表与详情、独立工作流声明列表、数据源诊断。
- 失败记录、工具配对结果、声明来源与历史完整性。
- 强提示“离线原型 · Codex 实时采集未验证”。
- 暖纸/墨色工业编辑风格、亮暗主题、键盘页签、筛选和窄屏布局。
- fragment 令牌读入内存后清除；不写浏览器存储。
- 前台 2 秒、后台 10 秒轮询，有超时和取消；401/403 清除授权和旧数据。
- 不显示虚构阶段、百分比、测试数、ETA 或 Agent 思考状态。

### 演示

[合成日志生成器](../companion/examples/generate_demo.py)只接受新目录，并明确写出 SYNTHETIC 标识。合成数据仅供原型测试，不使用生产 logger，不作为 C1 通过证据。

当前环境没有 pytest、coverage、mypy、ruff 和浏览器自动化依赖，未为满足工具清单安装外部依赖。测试使用标准库 unittest 和现有 Node 的 node:test；**不声称已达覆盖率目标、通过严格类型检查或完成视觉验收**。

## 5. 已知技术限制

1. 100 MiB 限制针对规范化元数据载荷，不是 SQLite 分配页、WAL、自有索引总磁盘硬上限；物理压缩、总磁盘预算仍待实现。
2. 文件替换检测使用 inode/文件代际、长度和前缀校验，无法证明任意同 inode、同长度、前缀之外覆写均被发现；不宣称 exactly-once 或防篡改。
3. 源路径符号链接祖先被拒绝，macOS `/var` 等别名可能需用户明确提供规范化真实路径；doctor 的临时缓存单独规范化。
4. 日志没有签名，host_observed 仅为格式分类，不能当作可信审计证据；哈希 ID 为稳定假名而非匿名化。
5. 本机恶意进程、被控制浏览器或源目录写入者不在令牌防护承诺内；HTTP 超时与连接上限不能替代生产级反 DoS。
6. 工具名不足以识别业务阶段，旧摘要无法证明对当前代码版本仍有效；界面保留未知状态。
7. 冷导入与文件轮转可能造成跨文件到达顺序差异，不用时间顺序做任务关联，也不将其当绝对业务因果顺序。
